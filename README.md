# CppME Chapter 19

This repository contains a set of C++ example programs for Chapter 19 of the "C++ Programming Made Easy" series. The examples focus on core object-oriented programming concepts such as classes, objects, member functions, encapsulation, constructors, validation, and basic data handling.

## Overview

The project is organized as a Visual Studio solution with multiple small standalone example programs. Each folder contains a separate C++ console project that demonstrates one concept from Chapter 19.

The root project also includes a minimal starter file (`CppME_Chapter19.cpp`) plus the Visual Studio solution and project files used to manage the examples.

## Repository Structure

- `CppME_Chapter19.cpp` – default starter program generated by Visual Studio for the main solution.
- `CppME_Chapter19.slnx` – solution metadata for the project.
- `CppME_Chapter19.vcxproj` – main Visual Studio C++ project configuration.
- `CppME_Chapter19.vcxproj.filters` – filter layout for solution explorer organization.
- `CppME_Chapter19_Example19.6/` – class with a setter and display method.
- `CppME_Chapter19_Example19.8/` – validation of a student mark using a range check.
- `CppME_Chapter19_Example19.10/` – class with name and age accessors.
- `CppME_Chapter19_Example19.14/` – simple fan control class with state and speed management.
- `CppME_Chapter19_Example19.16/` – bank account class with deposit and withdrawal logic.
- `CppME_Chapter19_Example19.18/` – student class combining fields and methods.
- `CppME_Chapter19_Example19.19/` – product inventory example with price and quantity validation.
- `CppME_Chapter19_Example19.24/` – employee information class with getters and setters.
- `CppME_Chapter19_Example19.25/` – ATM account example with deposit, withdrawal, and balance checking.

## Chapter Focus

Chapter 19 centers on using classes to model real-world objects. The examples in this repository demonstrate:

- Defining classes and objects
- Declaring private data members
- Writing public member functions
- Setting and retrieving values safely
- Validating numeric inputs
- Using constructors for initialization
- Organizing small C++ programs around object behavior

## Example Highlights

### Example 19.6 – Bank account state management

The `BankAccount` class stores a `balance` and exposes `setBalance()` and `displayBalance()`. The setter validates the input so negative balances are not accepted.

### Example 19.8 – Student marks with range checking

The `Student` class stores a `mark` and ensures it remains within the valid range `0..100`. Invalid values are reset to `0`.

### Example 19.10 – Person class with encapsulated data

This example introduces a `Person` class with a `name` and `age`. It demonstrates setter methods, getter methods, and simple validation for age.

### Example 19.14 – Fan object with state transitions

The `Fan` class maintains `speed` and `isOn` state. It demonstrates how object behavior can depend on current internal state and enforces valid fan-speed operation when the fan is on.

### Example 19.16 – Bank account operations

This version of the account class supports deposits and withdrawals, including validation checks. It shows how to protect the object state and report invalid operations.

### Example 19.18 – Student profile object

This example gives a student a name and mark, with validation on the mark and a combined display method to show both values.

### Example 19.19 – Product inventory object

`Product` stores a name, price, and quantity. It validates non-negative values and calculates the total inventory value.

### Example 19.24 – Employee information object

The `Employee` class stores the employee name and salary, with setter methods and getter methods to protect and retrieve the values safely.

### Example 19.25 – ATM account behavior

This example introduces a class that simulates basic ATM operations. It initializes the balance, allows deposits and withdrawals, and reports transaction failures when invalid values are entered.

## How to Build and Run

This repository is structured for Microsoft Visual Studio and uses `.vcxproj` files. To run an example:

1. Open the solution or the example project in Visual Studio.
2. Set the project as the startup project if needed.
3. Build the project.
4. Run it in Debug or Release mode.

If you are using a different C++ toolchain, each example folder contains a single `.cpp` file that can be compiled directly using a standard C++ compiler.

Example command (generic):

```bash
g++ -std=c++17 CppME_Chapter19_Example19.16.cpp -o example19_16
./example19_16
```
